Dependency change: Windows job/file transport is removed from Phase 0 and the Site
critical path. It is proven only when the planned audio connection is resumed after
S5-04, before actual narration. Portable project exports and Site backup/restore begin
in Phase 2, independent of audio/distribution. See [planned features](PLANNED-FEATURES.md).
Paid API substitution, significant downloads, hosted deployment and platform fallback
remain separate consequential decisions; the latest scope change does not approve spend.

The end-of-Phase-0 deployment-prompt deliverable precedes the phase-exit approval.
It must reference verified Site auth/storage/ChatGPT support, limits, mobile Site
checks and rollback. Do not require worker credentials or a tone player. Copying
the prompt does not authorize costs or deployment, and deferred audio is not a Site gate.
