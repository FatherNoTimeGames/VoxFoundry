## Atlas design proposal

A lore companion, not a game-progress checklist. Phone-first pan/pinch, touch-selectable
markers with accessible bottom-sheet details, 44px controls, search/filter/layers,
clustering where justified, saved views and desktop side panels. Uploaded background
images and annotations remain separate editable assets. Image-pixel coordinates
are explicit; geographic transforms/CRS are recorded only where known. No invented
latitude/longitude for a fictional image.

MapVersion identifies background digest, dimensions, coordinate system, applicable
world/game version, license/attribution and historical period. Markers/regions/routes
link library IDs, sources and manuscripts/narration; their placement classification
(verified/inferred/approximate/manual) is separate from draft/proposed/canon status.
Timelines represent uncertain bounds rather than fake exact dates. Saved views pin
map version, filters/layers and period. AI placement is a proposal with evidence and
confidence, never an automatic fact or canon promotion.

Leaflet is a candidate whose BSD 2-Clause code license is now verified; preserve its
notices/disclaimer if adopted. Its feature/release docs still need review, and its
code license does not license backgrounds/tiles/marker data. No dependency was selected
or installed in Phase 0. For original worlds, upload rights-cleared backgrounds first; AI image generation is a later opt-in
capability with cost/license approval. Labels, markers, borders and regions remain
editable regardless of the background generation method. Geographic reasoning must
use recorded map scale/uncertainty and version, not infer unsupported distances.
